### Why the underperformers underperform

- **`/private-pilot-training`, `/instrument-rating-training`:** Both already had their meta descriptions rewritten in PR #321/#322 (now lead with the live-now $55/hr instruction instead of "Targeting March 2027"). CTR is still low (0.51% / 0.29%) relative to decent-to-strong positions seen in the prior export (11.5 / 30.7 — this brief's table doesn't include position). **Hypothesis, not yet fully resolved:** the fix already applied addresses the snippet; remaining CTR weakness may be a ranking-position issue (if position hasn't moved much) rather than a snippet issue now, which the applied fix can't address on its own. Recommend waiting for the 28-day comparison already planned in `implementation-plan.md` P3 before concluding the snippet fix under- or over-performed.
- **`/programs`:** 0.48% CTR despite an already-live FAQPage schema and an already-accurate meta description. **New hypothesis this round:** `/programs`, `/apex-advantage`, and `/checkride-prep` meta descriptions all independently mention the same two core offerings ("Checkride Prep System" and "Private Instruction") in overlapping language — see next finding.
- **`/apex-advantage`: 0 clicks on 158 impressions is the single worst number in this table.** Its title/meta frame it as a "free portal signup" page ("Create a free Apex Advantage account for pilot study resources...") rather than a local-flight-school page. This is a plausible **query-intent mismatch**: if this page is being shown for commercial/local-training-intent searches (the kind that convert on `/checkride-prep` at 6.14%) rather than "pilot study app" searches, the snippet wouldn't match what the searcher wants, producing exactly this pattern (real impressions, zero clicks). **Flagged as a Search-Console-supported opportunity requiring a look at the page's actual matched queries (not available in this session without GSC API access) before rewriting its snippet** — rewriting blind risks fixing the wrong problem.
- **Self-competition risk, not yet quantified:** `/apex-advantage`, `/programs`, and `/checkride-prep` all reference "Checkride Prep System" and "Private Instruction" in their title/meta. This is a real duplicate-intent pattern worth resolving by giving each page a more distinct snippet focus (see Phase 3 proposals below), not by merging or removing any of them — per the brief, no duplicate-page removal without technical justification, and these three pages serve genuinely different funnel stages (portal signup vs. program overview vs. paid prep product).

## 4. Content-overlap inventory for the Phase 4/5 proposed pages (critical finding)

Before proposing new pages, checked for existing coverage, per the brief's own instruction and this session's established "content cluster, not content volume" discipline (`docs/seo/content-opportunities.md`, 2026-11-16).

### For "Instrument Proficiency Training in Austin" (proposed `/instrument-proficiency-training-austin`)

**This intent is already substantially covered by three existing assets:**
- `blog-ipc-what-to-expect.html` — "What to Expect From an IPC in Austin," full IPC walkthrough (14 CFR 61.57(d), ACS task areas, CFII's own debrief philosophy), CTA: *"We run IPC sessions in the actual aircraft, with a CFII, start to finish."* **[REPO]**
- `blog-ifr-currency-austin.html` — currency strategies, the 66 HIT rule. **[REPO]**
- `blog-instrument-currency-vs-instrument-proficiency.html` — the exact currency-vs-proficiency conceptual distinction the brief asks the new page to draw. **[REPO]**
- `pricing.html` already lists an **"IPC — Instrument proficiency check"** priced card (price currently "Announced Soon") and `programs.html`'s existing FAQ already states the IPC is done "in the aircraft... under 14 CFR 61.57(d)." **[REPO]**

**So the underlying service (IPC) is real and already confirmed** — this satisfies the brief's "do not claim an IPC is offered unless confirmed" condition. But building a 4th page on the same intent risks exactly the keyword-cannibalization the brief warns against. **Recommendation (for Gate 2 discussion, not yet decided):** build this as a **consolidating program page** — analogous in format to `/private-pilot-training` / `/instrument-rating-training` (a bookable-service page, not a blog post) — that itself internally links to and summarizes the three existing blog posts rather than re-explaining their content, with its own clear booking CTA. This is a defensible, distinct content type (program/service page vs. blog/informational), not a duplicate, provided it's built as a hub rather than a restatement.

**Open question needing your confirmation before Gate 2:** `pricing.html` shows IPC price as "Announced Soon" while `blog-ipc-what-to-expect.html`'s CTA reads as if IPC is fully bookable today ("we run IPC sessions... start to finish, reach out"). A new program page for this service needs to know which is actually true — is IPC bookable at a confirmed price today, or is pricing still pending? This affects the new page's CTA wording and is **not something I can resolve from the repo alone.**

### For "Instrument Checkride Preparation in Austin" (proposed `/instrument-checkride-prep-austin`)

**Genuine gap, already identified in the 2026-11-16 round** (`content-opportunities.md` Topic 1) and still true today: `checkride-prep.html`'s own FAQ/schema explicitly states instrument content is "in development" — not live. No existing page covers instrument oral-exam/ACS prep specifically. **This page is a real opportunity, not a duplicate**, provided (per the brief's own instruction) it routes its CTA to the confirmed-live **Private Instruction** service rather than implying the (not-yet-live-for-instrument) Checkride Prep system covers it — exactly the distinction already encoded in the FAQ added to `/instrument-rating-training` in PR #322 ("Does the Checkride Prep system cover the instrument checkride? Not yet...").

## 7. Phase 5 evaluation

### Aircraft Transition Training (`/aircraft-transition-training-austin`) — recommend: do not build now

`fleet.html` confirms the entire planned fleet is **one** Piper PA-28, itself still under lease negotiation, not yet confirmed. **[REPO]** There is no second aircraft type in Apex's own fleet to "transition" between, and the PA-28 itself doesn't exist as an operating asset yet. The prior round's GSC data showed only weak signal for this intent (19 impressions, position ~13, **[GSC-HISTORICAL]**) with no fresh evidence in this round's table either.

**Recommendation: hold.** Revisit only once the PA-28 lease is actually signed and the aircraft is in service. No page, no content change proposed at this time.

### Taylor Municipal Airport page (`/flight-training-taylor`) — recommend: keep existing URL, small link fix, no new page

This page is already unusually thorough and honest: real airport data (runway 17/35, ~4,000 ft, CTAF 122.8, AWOS 119.75), an explicit "What Remains Unconfirmed" section, a full FAQ, and proposed (clearly labeled not-yet-locked) rates. **[REPO]** Per the brief's own preference ("prefer improving the existing URL rather than creating a competing page") and given how complete this page already is, **the only concrete improvement identified is the internal-linking gap in Section 6 above** (hyperlink the 4 service cards). No evidence was found to justify a larger content expansion, and no second Taylor-focused page is recommended — that would risk exactly the doorway-page pattern the brief explicitly warns against.
