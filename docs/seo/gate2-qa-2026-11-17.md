### 2. Structured-data QA — syntax, schema validity, and rich-result eligibility reported separately

As instructed, these are **three distinct findings**, not one conflated claim:

**Syntax validation:** Both JSON-LD blocks (`Course`, `FAQPage`) parse without error (`JSON.parse`, re-verified this round). No malformed syntax.

**Schema validity (schema.org vocabulary):** Both blocks use valid Schema.org types and properties in the correct shape — `Course` carries `name`, `description`, `provider.{@type,name,url}`, `courseMode`, `url`; `FAQPage.mainEntity` is an array of `Question` objects each with one `acceptedAnswer.Answer.text`, matching the spec's required nesting. No structural defects found; no correction was needed to the shape of the markup itself.

**Google rich-result eligibility — checked directly against Google's own documentation changelog, not assumed from the above:**
- **Course rich results were discontinued by Google on September 9, 2025** — Google's Search Central changelog states plainly: *"These structured data types are no longer shown in Google Search results."* This predates this page's creation; the `Course` markup here (and the identical pattern already live on `/private-pilot-training` and `/instrument-rating-training`) is schema-valid but **not currently eligible for any Google rich result**, regardless of its property completeness.
- **FAQ rich results were discontinued by Google on May 7, 2026** — confirmed via two separate Google changelog entries: a May 8, 2026 entry ("Deprecating the FAQ rich result feature... This feature will no longer appear in Google Search starting May 7, 2026") and a June 15, 2026 entry removing the feature's own documentation page ("The FAQ rich result feature is no longer shown in Google Search results"). The `FAQPage` markup here (and the same pattern on `/programs`, `/checkride-prep`, `/pricing`, `/instructors`, and `/instrument-rating-training` from earlier work this session) is schema-valid but **not currently eligible for a Google FAQ rich result.**

**What this means, stated plainly:** valid JSON + valid schema.org shape ≠ Google rich-result eligibility. Neither type will produce a visible rich result in Google Search today. **This is not a defect in this page's markup — there is nothing to "fix."** The markup remains harmless, schema.org-valid, and may still be read by other consumers (other search engines, AI/LLM answer-engine crawlers, accessibility tooling) — several industry sources note Google has said unused/non-rich-result-eligible structured data doesn't cause ranking harm. No markup was removed or changed as a result of this finding. **This also applies to the Course/FAQPage schema already live on other pages from earlier work this session — flagged here for your awareness, not corrected, since that's outside this PR's scope** (each of those pages would need its own authorized round of edits).
